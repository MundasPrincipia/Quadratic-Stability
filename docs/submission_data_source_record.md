# RF data sources and recorded terms

S1 is the LoRa_RFFI dataset of Shen et al., DOI 10.21227/qqt4-kz19.
The provider's GitHub README states CC BY-NC-SA 4.0. Earlier project
records also report a CC BY 4.0 notice on IEEE DataPort; the applicable
license for the acquired version must be established before redistribution.
GitHub: https://github.com/gxhen/LoRa_RFFI/blob/main/Openset_RFFI_TIFS/readme.md

S4 is the Oregon State LoRa collection of Elmaghbub and Hamdaoui.
Its official release note permits research use and requests citation,
but does not explicitly specify redistribution of derived per-sample arrays.
Release note:
https://research.engr.oregonstate.edu/hamdaoui/sites/research.engr.oregonstate.edu.hamdaoui/files/release_note_2021.pdf

The package contains per-sample complex states, features and labels, as
well as learned parameters and result summaries. Excluding original IQ
does not itself resolve the distribution terms for the per-sample arrays.
No new license for third-party or derived data is granted by this package.
The outstanding check concerns these RF data files; it is not a finding
that the manuscript, all original code, or all aggregate results lack
publication rights. Confirm the applicable scope before distributing the
data-containing companion. No permission request or external upload has
been made in preparing these files.

Raw-IQ reconstruction additionally requires provider recordings and the
original selection metadata. The companion is not an end-to-end raw-IQ
training release.
