# RF data sources

The repository contains processed S1/S4 states, features and labels, saved
classifier parameters, and experiment records from the submission materials.
The [acquisition guide](data_acquisition_and_processing.md) gives the source
links, paper citations, selected subsets, and processing steps.

- **S1:** LoRa_RFFI_dataset, DOI
  [10.21227/qqt4-kz19](https://doi.org/10.21227/qqt4-kz19). The
  [DOI metadata](https://api.datacite.org/dois/10.21227/qqt4-kz19) records
  CC BY 4.0; the [provider README](https://github.com/gxhen/LoRa_RFFI/blob/main/Openset_RFFI_TIFS/readme.md#license)
  states CC BY-NC-SA 4.0 for its dataset and code. These source statements
  are retained as reported rather than replaced by a repository software license.
- **S4:** Oregon State LoRa collection of Elmaghbub and Hamdaoui. The
  [official release note](https://research.engr.oregonstate.edu/hamdaoui/sites/research.engr.oregonstate.edu.hamdaoui/files/release_note_lora_datasets_final_oct2023_v2.pdf)
  permits research use and requests citation of the associated IEEE Access
  paper. It does not explicitly state redistribution terms for derived
  per-sample arrays.

The [source-term record from the submission archive](submission_data_source_record.md)
is preserved unchanged. It records the distribution questions identified when
that archive was prepared. Software licensing remains pending.
